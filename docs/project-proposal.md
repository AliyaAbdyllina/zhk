## 1. Название и организация

* **Название системы:** Система управления заявками на закупку материалов
* **Организация / подразделение:** АО «Кукморский завод Металлопосуды», отдел снабжения
* **№ из таблицы примеров (если брали):** 50 / тема изменена под процесс закупки материалов

Система предназначена для регистрации и обработки заявок на закупку материалов, необходимых для работы предприятия. Основной процесс связан с созданием заявки, назначением ответственного специалиста и изменением её статуса до завершения или отмены.

## 2. Главная сущность и справочник

* **Главный объект:** заявка на закупку материала
* **Справочник:** материалы
* **Поле-ссылка:** `materialId`

Одна заявка содержит информацию о необходимости закупки конкретного материала. В заявке хранится числовая ссылка `materialId` на запись справочника материалов.

## 3. Роли и права

| Роль                          | Создаёт | Назначает исполнителя | Меняет статус          |
| ----------------------------- | ------- | --------------------- | ---------------------- |
| Сотрудник отдела снабжения    | да      | да                    | нет                    |
| Специалист по закупкам        | нет     | нет                   | да, только свою запись |
| Руководитель отдела снабжения | нет     | да                    | нет                    |

Сотрудник отдела снабжения регистрирует поступившую потребность в материале и при необходимости назначает специалиста по закупкам. Специалист по закупкам работает только с назначенными ему заявками и изменяет их статус. Руководитель отдела может просматривать заявки и назначать исполнителей.

## 4. Сценарий в одно предложение

Сотрудник отдела снабжения создаёт заявку на закупку материала, назначает специалиста по закупкам, после чего назначенный специалист переводит свою заявку в работу и завершает или отменяет её.

## 6. Что не входит в семестр

В рамках семестра система ограничивается регистрацией и обработкой заявок.

Не входят:

1. Реальное оформление закупки у поставщика.
2. Оплата материалов и работа с бухгалтерскими документами.
3. Отправка SMS и других внешних уведомлений.

## 7. Запас под ВКР

В дальнейшем систему можно расширить, но эти возможности не реализуются в рамках текущего семестра:

1. Добавить количество материала, единицу измерения, требуемую дату и приоритет заявки.
2. Добавить историю изменения статусов и действий пользователей по каждой заявке.
3. Реализовать связь с системой складского учёта для автоматической проверки текущих остатков материалов.
4. Реализовать интеграцию с 1С или другой системой предприятия для передачи данных о закупках.
5. Добавить аналитику по расходу материалов и количеству заявок за выбранный период.
6. Добавить работу с поставщиками и хранение истории выполненных закупок.

## 8. Чем не копия соседа

Система разрабатывается для конкретного предприятия — АО «Кукморский завод Металлопосуды». Главный объект системы — заявка на закупку материала, а справочником является перечень материалов. В отличие от типовых заявок на ремонт или обращений, процесс связан с обеспечением предприятия необходимыми материалами и распределением заявок между специалистами отдела закупок.
